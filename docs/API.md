# API

Venn's JSON API is served under `/api` by both the Cloudflare Worker and the Node server. Writes must be sent as `application/json`. Times are UTC milliseconds.

## Endpoints

| Method           | Path                                 | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------- | ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST`           | `/api/events`                        | Create a poll → `{ id, adminToken }`. Specific times: `{ mode: "options", options: [{ start, end }] }` (UTC ms; up to 14 days long). Whole days: `slotMinutes: 1440`, with `durationMinutes` a multiple of 1440 to look for several days in a row. Hours that differ by day: `windows: [{ date, start, end }]` (minutes after midnight in the poll's time zone), with `slotMinutes` (default 30) and `durationMinutes`. Parts of the day: `layout: "parts"`, each option a morning (9–12), afternoon (12–5) or evening (6–10). Optional `location` and `emoji`, and the privacy settings below. `hostAnswers: true` saves the organizer's own answer and returns it as `participant: { id, editToken }`: `hostAvailability` (option start → `2` or `1`) if given, otherwise yes to every time offered |
| `GET`            | `/api/events/:id`                    | Poll and responses. Sending the `x-admin-token` header sets `isAdmin`; `x-edit-token` gets your own answer back in full.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `PUT`            | `/api/events/:id`                    | Change the poll: the same body as creating one. Organizer only, and only while nobody but the organizer has answered (`409` after that). The organizer's own answer follows the new times.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `DELETE`         | `/api/events/:id`                    | Organizer only                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `PUT`            | `/api/events/:id/settings`           | `{ requireEmail?, hideNames?, hideResults? }`, each `true` or `false` → all three. Organizer only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `POST`           | `/api/events/:id/participants`       | `{ name, availability, email?, copyTo? }` → `{ id, editToken }`. `email` is required when the poll has `requireEmail`. `copyTo` emails the person a copy.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `PUT` / `DELETE` | `/api/events/:id/participants/:pid`  | Needs `x-edit-token`. The organizer can also delete.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `POST`           | `/api/events/:id/finalize`           | `{ start }`, or `{ start: null }` to clear. Organizer only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `GET`            | `/api/events/:id/event.ics`          | Calendar file for the picked time                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `GET` / `PUT`    | `/api/events/:id/notifications`      | Email and webhook settings. Organizer only. See [Notifications](NOTIFICATIONS.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `POST`           | `/api/events/:id/notifications/test` | Send a test webhook. Organizer only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `GET`            | `/api/config`                        | Which optional features (email, calendars, AI) this server has turned on                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `POST`           | `/api/ai/draft-poll`                 | `{ prompt, timezone }` → a draft poll. See [AI features](AI.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `POST`           | `/api/events/:id/ai/:kind`           | `summary` and `message` (organizer only), `answer` (anyone)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## Privacy settings

Organizers can switch these on when creating a poll (`POST /api/events`) or later (`PUT /api/events/:id/settings`). The server enforces them, so hidden data never reaches other guests:

| Setting        | What it does                                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `requireEmail` | Everyone who answers must send an `email`. Only the organizer sees it: each response has an `email` field for the organizer, and for the person who gave it. |
| `hideNames`    | Other guests see each response named `Guest 1`, `Guest 2`… The answers still show, so everyone can see which dates work.                                     |
| `hideResults`  | Other guests get only their own response, plus `responses`: how many people have answered. The picked date still shows once the organizer picks it.          |

## Availability

`availability` maps each option's start time (UTC ms) to `2` (yes) or `1` (if needed). Anything missing means no.

```json
{ "name": "Ana", "availability": { "1793804400000": 2, "1793818800000": 1 } }
```

## Authentication

There are no accounts. Two secrets, both returned once when they're created, prove who you are:

- **`adminToken`** (from `POST /api/events`): send it as `x-admin-token` for organizer-only calls.
- **`editToken`** (from `POST /api/events/:id/participants`): send it as `x-edit-token` to change or remove that response.

The server stores only SHA-256 hashes of these tokens. In the web app they live in the URL fragment and the browser's local storage.

## Errors

Errors come back as JSON with an HTTP status: `{ "error": "This poll does not exist or was deleted" }`. Validation problems are `400`, missing permissions `403`, and unknown polls `404`.
